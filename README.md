# 多步驟計算練功房

給國小孩子練習多步驟計算的網頁，只有一個 `index.html`，不用安裝，打開就能用。

## 題型
- 加減多步驟、連乘、連除、乘除混合、四則混合：可以調整位數（最多 6 位）和步驟數（2–4 步），也可以設定有沒有括號
- 情境題：生活中的應用問題，數字最多 5 位，每次隨機產生

## 練習模式
- 限時衝刺 5 分鐘、15 題挑戰、情境題 15 題、錯題重練、今日任務
- 作答方式：快答（只寫答案）或逐步作答（每一行寫出計算結果）
- 計分挑戰：一輪三項（限時衝刺每答對 1 題得 2 分，15 題挑戰和情境題每答對 1 題得 1 分），可以放棄單項，三項都完成或放棄後結算總分

## 其他
- 學習紀錄：正確率與速度曲線、錯誤類型分析、錯題本
- 家長設定：等級或自訂難度、自適應難度、家長密碼鎖
- 學習單：產生可列印的練習單，附答案頁

練習紀錄存在瀏覽器的 localStorage 裡，換瀏覽器或清除網站資料後紀錄就不會保留。
